# ng-quran (QuranFlow)

Progressive Web App for prayer times, Quran reading with audio, Qibla compass, and related features—built with Angular.

## Development

```bash
npm install
npm start
```

Open `http://localhost:4200/`. The dev server listens on all interfaces (`0.0.0.0`).

### Other scripts

- `npm run build` — production build (output in `dist/`)
- `npm test` — unit tests (Vitest)
- `npm run start:https` — dev server with local SSL (see `ssl/`)

## Documentation

Extended notes (summaries, implementation details, checklists) live in `.docs/` at the project root. That folder is intentionally **not** committed; keep it local or sync it outside the repo if you need it on other machines.
